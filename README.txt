NOORÉ JEWELLERY WEBSITE

How to preview:
1. Open index.html in a modern browser.
2. For best results, run a local server (for example: python -m http.server 8000).

- Wishlist buttons
- Category filters and sorting
- Dynamic product pages
- Search
- Demo checkout flow

Before launching a real store, connect the checkout to Shopify/WooCommerce or a custom backend, add your real products, policies, WhatsApp number, domain, analytics and payment gateway.
